# 工作流引擎项目规划 - 第三轮讨论

## 概述

第三轮讨论聚焦于前端编辑器细化、用户体验、移动端适配、帮助文档和定价策略。前两轮已完成核心架构设计（MVP 功能、异步执行引擎、节点系统），本轮补充前端交互设计和商业化规划。

## 二、前端编辑器功能细化

### 2.1 技术选型：React Flow

**推荐方案**：React Flow + 自定义扩展

| 维度 | 选型 | 理由 |
|------|------|------|
| 核心库 | React Flow 11.x | 成熟稳定，节点系统完善 |
| 状态管理 | Zustand | 轻量、简单、与 React Flow 兼容 |
| 布局算法 | Dagre | 支持层次布局，集成简单 |
| 虚拟化 | react-flow-renderer viewport | 原生支持视口裁剪 |

### 2.2 节点面板设计

```
┌─────────────────────────────────────────────────────────────┐
│  节点面板                              │   画布区域         │
│  ┌─────────────────────────────────┐  │                    │
│  │ 触发器                           │  │    ┌─────┐       │
│  │  [Webhook] [定时] [手动]        │  │    │START│       │
│  ├─────────────────────────────────┤  │    └──┬──┘       │
│  │ 执行                             │  │       │          │
│  │  [LLM] [HTTP] [代码]            │  │    ┌──┴──┐       │
│  ├─────────────────────────────────┤  │    │     │       │
│  │ 逻辑                             │  │ ▼   ▼     ▼       │
│  │  [条件] [并行] [延迟]           │  │ ┌─────┐ ┌─────┐   │
│  ├─────────────────────────────────┤  │ │HTTP │ │ LLM │   │
│  │ 数据                             │  │ └─────┘ └─────┘   │
│  │  [变量设置] [JSON解析]          │  │                    │
│  └─────────────────────────────────┘  └────────────────────┘
│                              │
│                    [属性配置面板]
```

**节点分类**：
- 触发器：Webhook、定时、手动、API
- 执行：LLM、HTTP、代码（JavaScript）、数据库
- 逻辑：条件分支、并行分支、延迟
- 数据：变量设置、JSON 解析、数组处理

### 2.4 连线与条件编辑

**连线类型**：
1. 普通连线：无条件，顺序执行
2. 条件连线：带表达式，如 `{{score}} > 60`
3. 并行分支：带分支索引

**条件编辑器**：
```
┌────────────────────────────────────────────────────────────┐
│  条件编辑:                                                 │
│  ┌──────────────────────────────────────────────────────┐ │
│  │ 变量              │ 比较符          │ 值              │ │
│  ├───────────────────┼─────────────────┼─────────────────┤ │
│  │ output.sentiment │ [等于 ▼]        │ [positive    ]  │ │
│  │                   │ [包含 ▼]        │ [____        ]  │ │
│  │                   │ [大于 ▼]        │ [____        ]  │ │
│  └──────────────────────────────────────────────────────┘ │
│  表达式预览: {{output.sentiment}} == "positive"           │
│  [添加条件] [添加分组 (AND/OR)]                            │
└────────────────────────────────────────────────────────────┘
```

## 三、用户体验设计

### 3.1 核心操作流程

| 场景 | 操作路径 | 优化点 |
|------|----------|--------|
| 创建流程 | 空白画布 / 从模板选择 | 提供 5+ 起步模板 |
| 添加节点 | 拖拽 / 双击面板 | 智能吸附、自动布局 |
| 连接节点 | 拖拽连线 / 自动吸附 | 防止环、实时校验 |
| 配置节点 | 点击节点 / 右侧面板 | TAB 切换、即时保存 |
| 执行流程 | 右上角"运行"按钮 | 快速测试、调试模式 |
| 保存发布 | Ctrl+S / 右上角发布 | 版本自动保存、草稿箱 |

### 3.2 快捷操作

| 操作 | 快捷键 | 说明 |
|------|--------|------|
| 保存 | Ctrl/Cmd + S | 自动保存到草稿 |
| 撤销 | Ctrl/Cmd + Z | 撤销上一步操作 |
| 重做 | Ctrl/Cmd + Shift + Z | 重做 |
| 删除 | Delete / Backspace | 删除选中节点/连线 |
| 复制 | Ctrl/Cmd + C | 复制选中节点 |
| 粘贴 | Ctrl/Cmd + V | 粘贴节点 |
| 全选 | Ctrl/Cmd + A | 选中所有节点 |
| 放大 | Ctrl/Cmd + = | 放大画布 |
| 缩小 | Ctrl/Cmd + - | 缩小画布 |
| 居中 | Ctrl/Cmd + 0 | 视图居中到内容 |

### 3.3 反馈机制

| 场景 | 反馈形式 |
|------|----------|
| 保存成功 | 右下角 Toast 提示"已保存"，3秒自动消失 |
| 保存失败 | 弹窗显示错误原因，提供重试按钮 |
| 节点验证失败 | 节点右上角红色标记，悬停显示错误 |
| 执行中 | 节点边框蓝色闪烁，进度百分比 |
| 执行成功 | 节点右上角绿色对勾 |
| 执行失败 | 节点右上角红色叉号，点击展开错误详情 |
| 连线无效 | 连线红色虚线，提示"检测到循环" |

### 3.4 调试体验

**单步调试模式**：
```
┌─────────────────────────────────────────────────────────────┐
│  调试模式: [开启]  当前节点: HTTP_1                        │
├─────────────────────────────────────────────────────────────┤
│  变量状态:                                                   │
│  {                                                          │
│    "input": { "userId": "123" },                          │
│    "http_response": { "status": 200, "data": {...} },    │
│    "llm_output": null                                     │
│  }                                                         │
│                                                             │
│  操作: [下一步] [跳过本节点] [终止] [查看日志]              │
└─────────────────────────────────────────────────────────────┘
```

**断点设置**：
- 点击节点 → 设置断点
- 断点处暂停，显示当前变量
- 支持条件断点（仅当变量满足条件时暂停）

### 4.2 移动端功能裁剪

| 功能 | Desktop | Tablet | Mobile |
|------|---------|--------|--------|

| 场景 | 优化方案 |

## 五、帮助文档与引导

### 5.1 新手引导

**引导流程**（首次登录）：

1. **欢迎页**（1分钟）
   - 产品介绍视频（30秒）
   - "开始创建第一个流程"按钮

2. **创建流程**（2分钟）
   - 步骤1：选择"从空白开始"
   - 步骤2：拖拽 START 节点
   - 步骤3：拖拽 HTTP 节点并连接
   - 步骤4：配置 HTTP 请求
   - 步骤5：拖拽 END 节点并连接

3. **运行流程**（1分钟）
   - 点击运行按钮
   - 查看执行结果

4. **完成引导**
   - 展示Congratulations动画
   - 引导进入模板中心

## 六、定价策略与商业模式

### 6.1 定价模型

**推荐模型**：混合计费（订阅 + 用量）

| 计费维度 | 说明 |
|----------|------|
| 订阅费 | 基础功能按月/年收费 |
| 执行费 | 超出免费额度后按次计费 |
| API 调用 | 外部 API 调用按量收费 |
| 存储费 | 大规模数据存储单独计费 |

### 6.2 套餐设计

| 维度 | 免费版 | 专业版 | 企业版 |
|------|--------|--------|--------|
| **价格** | ¥0/月 | ¥99/月 | 定制 |
| **工作流数** | 3 | 50 | 不限 |
| **执行次数/天** | 100 | 10,000 | 不限 |
| **团队成员** | 1 | 10 | 不限 |
| **节点类型** | 基础 5 种 | 全部 | 全部 |
| **插件** | 无 | 5 个 | 不限 |
| **版本历史** | 5 个 | 50 个 | 不限 |
| **执行记录保留** | 7 天 | 30 天 | 1 年 |
| **支持** | 社区 | 邮件 | 专属客服 |
| **SLA** | 无 | 99.5% | 99.9% |

### 6.3 用量计费细节

**超额计费**：
```
专业版超出执行次数:
- 1-1000 次: ¥0.01/次
- 1001-10000 次: ¥0.005/次
- 10000+ 次: ¥0.001/次

存储超出:
- 1-10GB: ¥0.5/GB/月
- 10GB+: ¥0.2/GB/月
```

### 6.4 商业模式

**收入来源**：

| 来源 | 占比 | 说明 |
|------|------|------|
| 订阅费 | 60% | 月/年订阅 |
| 用量费 | 25% | 执行次数、存储 |
| 插件市场 | 10% | 开发者分成 |
| 企业定制 | 5% | 私有部署、培训 |

**生态建设**：

1. **插件市场**
   - 官方插件：免费
   - 社区插件：开发者定价，平台抽成 20%
   - 认证插件：官方审核，标记"已认证"

2. **模板市场**
   - 免费模板：官方提供
   - 付费模板：开发者发布，定价 $1-$50

3. **开发者生态**
   - 节点 SDK：免费提供
   - 文档与教程：免费
   - 开发者社区：官方运营

## 七、第三轮实现挑战

### 7.1 前端编辑器挑战

**挑战1：复杂流程性能**

| 问题 | 方案 |
|------|------|
| 100+节点渲染卡顿 | 虚拟化 + React.memo |
| 缩放/平移不流畅 | Canvas 分层 + requestAnimationFrame |
| 节点定位效率低 | Web Worker 预处理布局 |

**挑战2：状态同步**

| 问题 | 方案 |
|------|------|
| 撤销/重做状态管理 | 命令模式 + 状态栈 |
| 多端协作冲突 | OT 算法 / CRDT |
| 意外关闭丢失数据 | 自动保存 + localStorage |

### 7.2 移动端挑战

**挑战3：功能裁剪决策**

| 问题 | 方案 |
|------|------|
| 移动端编辑能力边界 | 仅支持查看 + 简单配置 |
| 触控交互精度 | 增大可点击区域 |
| 小屏幕信息密度 | 分层展示 + 抽屉模式 |

### 7.3 商业化挑战

**挑战4：计费准确性**

| 问题 | 方案 |
|------|------|
| 执行计数精确统计 | Redis 计数器 + 定期落库 |
| 防止恶意刷单 | 限流 + 异常检测 |
| 计费账单生成 | 日结 + 月结账单 |
